# 강호비급 (江湖祕笈)

무명의 협객이 초식을 모아 강호를 등반하는 덱빌딩 로그라이크.

**▶ 플레이: https://flyest1.github.io/gangho-bigeup/**

김용(金庸) 원작의 세계관과 인물명을 참조한 **비공식·비영리 팬메이드** 작품입니다.
원작 문장과 원작 저작물은 사용하지 않으며, 모든 대사와 텍스트는 새로 썼습니다.
수익화하지 않습니다.

## 특징

- **자세(勢)와 상성** — 외공▶경공▶내공▶외공. 낸 카드의 계열이 곧 내 자세가 되고,
  상대의 자세를 누르는 계열로 치면 위력이 오르며 호신강기를 무시한다(파훼).
  적의 공격에도 같은 규칙이 적용되므로 자세 관리가 공수 양면의 판단이 된다.
- **연계(連繫)** — 같은 계열을 3장 연속 내면 계열 보너스가 매 장 발동한다.
  상성을 쫓아 계열을 갈아타면 연계가 끊긴다.
- PWA — 설치 가능하며 오프라인에서 플레이된다.
- **아트·사운드** — 카드 문양·적 얼굴은 전부 런타임에 그리는 SVG이고, 효과음은
  오실레이터로 합성한다. 이미지 자산은 보스 초상 3장뿐이다.
  보스 초상 3장은 같은 제작자의 sajo-game 프로젝트에서 자체 제작한 것을 가져왔습니다.

## P1에서 실제로 나온 것

- **1개 문파** — 개방(丐幇). 2개 문파(고묘파·소림)는 P2 이후.
- **축약 3막**, 막마다 6층. 관문(보스) 3인: 1막 매초풍, 2막 구천인, 3막 구양봉.
- **초식 60장**, **기물 20종**, **적 18종**(그중 정예 3·보스 3).
- 자세(勢)·상성·연계 규칙 전부, 맵 노드(격전·정예·객잔·장터·관문), 저장/이어하기.
- PWA — 홈 화면 설치, 오프라인 플레이, 새 판본 알림.
- 접근성 — 스크린리더용 aria-label, 초점 관리, 색맹 대응(기호+텍스트 병기).

## P1 이후 마감(P1.5)

P1 리뷰와 두 차례의 브라우저 검증에서 나온 잔여 항목을 닫았다.

- 맵·객잔·장터·보상 화면에 **보유 기물** 표시 (전에는 전투 중에만 보였다)
- **탭 두 개** 감지 — 나중에 연 탭이 저장을 쥐고, 먼저 연 탭은 저장을 멈추고
  그 사실을 알린다. 되찾을 때는 저장소의 최신 판을 다시 읽는다.
- 순수성 검사기 구멍 4종(`self` 우회·`.jsx` 미스캔·확장자 대소문자·면제 상한이
  위반 수가 아닌 줄 수를 세던 문제)과 검사기 자체의 테스트
- **마스커블 아이콘**을 안전지대에 맞춰 재생성, `apple-touch-icon` 링크 추가
- 결과 화면에 최종 체력 표시
- 좁은 화면(360×640)에서 알림이 쌓여도 손패가 눌리지 않도록 축소 순서를 명시

## P2 이후로 미룬 것

설계서에서 처음부터 P2+로 배정된 항목들이다.

- 기연·비급 노드 (맵 노드 종류 확장)
- 고묘파·소림 2개 문파 추가
- 승단 15단 (반복 플레이 난이도 사다리)
- 메타 해금 (완주 보상으로 콘텐츠 개방)
- 저주 카드
- 보스 2단계 패턴
- 게임패드 입력

## 개발

```bash
npm install
npm run dev          # 개발 서버
npm run test         # 엔진 단위 테스트
npm run validate     # 데이터 무결성 검증
npm run check:purity # 엔진이 DOM/전역 난수를 참조하지 않는지 검사
npm run typecheck    # tsc --noEmit
npm run build        # 프로덕션 빌드
npm run verify:build # 빌드 산출물(앱 셸·매니페스트·서비스워커·아이콘) 검증
npm run test:e2e      # Playwright 브라우저 스모크(데스크톱·모바일)
npm run balance       # 자동 플레이 시뮬레이션(완주율 추정)
npm run icons         # 마스커블 아이콘 재생성(icon-512에서 안전지대에 맞춰 축소)
```

`.github/workflows/deploy.yml`이 push 시 위 전체(검증→순수성→타입→단위테스트→
빌드→빌드검증→브라우저 스모크)를 통과해야 GitHub Pages로 배포한다.

## 구조

`src/engine/`은 DOM을 모르는 순수 로직이고 `src/ui/`는 렌더만 담당한다.
모든 무작위는 직렬화 가능한 시드 RNG 하나를 경유하므로 런 전체가 재현 가능하다.
카드·기물·적은 `src/data/*.json`의 효과 원자 배열로 선언한다.
`tests/engine/`은 엔진·화면 단위 테스트, `tests/e2e/`는 실제 브라우저로 도는
스모크 테스트다.
